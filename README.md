
# 🎮 ESCOLHAS

### Uma vida de decisões duvidosas.

ESCOLHAS é um jogo de histórias interativas e comédia, onde cada decisão pode mudar completamente o rumo da aventura.

## Recursos

- Sistema de escolhas e consequências.
- Criação de personagem.
- Pet shop com diversos animais.
- Dinheiro e fome.
- Histórias ramificadas.
- Eventos engraçados.
- Salvamento de progresso.

## Tecnologias

- HTML5
- CSS3
- JavaScript
